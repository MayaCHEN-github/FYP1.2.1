# 结果文件格式

## leak_test 单次结果

路径：`results/{model}_{prompt_key}_{timestamp}.json`

### metadata

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `model` | string | 模型别名 |
| `prompt` | string | prompt 键名 |
| `seed` | string | 种子键名 |
| `system_message` | string | 系统提示键名 |
| `timestamp` | string | `YYYYMMDD_HHMMSS` |
| `total_tests` | int | 重复次数 |
| `bypass_count` | int | TP |
| `defense_success_count` | int | TN |
| `defense_failure_count` | int | FP |
| `irrelevant_count` | int | FN |
| `bypass_rate` | float | 绕过率 |
| `defense_success_rate` | float | 防御成功率 |
| `confusion_matrix` | object | `{TP, FP, TN, FN}` |
| `metrics` | object | `{Accuracy, Precision, Recall, F1 Score}` |

### detailed_results[]

| 字段 | 含义 |
| --- | --- |
| `test_number` | 第几次重复（1-based） |
| `contains_leak` | 正则泄露检测 |
| `contains_refusal` | 模型拒绝检测 |
| `leakage_details` | 泄露检测描述文本 |
| `refusal_details` | 拒绝检测描述文本 |
| `response` | 模型完整输出 |

## auto_prompt_test 汇总

路径：`results/summary_{model}_{timestamp}.json`

| 顶层键 | 含义 |
| --- | --- |
| `metadata.model` | 被测模型 |
| `metadata.timestamp` | 汇总时间 |
| `prompt_stats` | 每个 prompt 的 metadata / confusion_matrix / metrics 快照 |
| `detailed_results` | 各次 `leak_test` 完整结果列表 |

## analyze_results 输出

路径：`analysis_results/analysis_summary.json`

| 顶层键 | 含义 |
| --- | --- |
| `model_analysis` | 按模型 → prompt → 聚合计数 |
| `prompt_analysis` | 按 prompt → 模型 → 聚合计数 |

热力图 PNG（同目录）：

- `tp_count_heatmap.png`
- `tn_count_heatmap.png`
- `fp_count_heatmap.png`
- `fn_count_heatmap.png`
- `leak_count_heatmap.png`
- `rejection_count_heatmap.png`

`analyze_results.py` 从**文件名**解析模型与 prompt 类型；命名需保持 `{model}_prompt_{type}{n}_{timestamp}.json` 或 `{model}_prompt{n}_{timestamp}.json` 风格，否则该文件会被跳过。
